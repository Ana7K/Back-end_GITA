1.1. რა მონაცემთა ტიპები ვიცით JavaScript-ში? (Primitive vs Non-Primitive)
Primitive data types: string, number, boolean, bigint, null, undefined, symbol
Non-Primitive data types: Object, რომელშიც მოიაზრება Function და Array
Primitive მონაცემთა ტიპები ინახავენ მნიშვნელობებს პირდაპირ მეხსიერებაში და წინასწარ განსაზღვრულია პროგრამირების ენით.
ხოლო non-primitive მონაცემთა ტიპები ინახავენ მნიშვნელობების კოლექციებს და ინახავენ reference value-ს ანუ მეხსიერების მისამართს, რომელიც მიუთითებს რეალურ მონაცემებზე.

1.2. რა განსხვავებაა ცვლადის გამოცხადების ტიპებს შორის: var, let და const?

var - ცვლადს აქვს function scope ან global scope. შესაძლებელია მისი მნიშვნელობის შეცვლა და ასევე იმავე scope-ში ხელახლა გამოცხადება.
let - ცვლადს აქვს block scope. შესაძლებელია მისი მნიშვნელობის შეცვლა, მაგრამ იმავე block-ში ხელახლა გამოცხადება შეუძლებელია.
const - ცვლადსაც აქვს block scope, თუმცა მისი მნიშვნელობის ხელახლა მინიჭება შეუძლებელია თავდაპირველი მინიჭების შემდეგ. მაგრამ თუ ობიექტს ან მასივს განვიხილავთ, მისი შიდა მონაცემების შეცვლა მაინც შესაძლებელია.

კომპილაციის დროს JavaScript ადეკლარირებს ცვლადებს მათი scope-ის დასაწყისში, თუმცა ინიციალიზაცია განსხვავებულად ხდება.
var - ცვლადი hoisting-ის დროს დეკლარირდება და ინიციალიზდება undefined-ით. ამიტომ მისი გამოყენება შესაძლებელია იმ ხაზამდე, სადაც ცვლადი რეალურად არის დეკლარირებული და ეს შეცდომას არ გამოიწვევს.
let და const - ასევე hoist-დება, თუმცა დეკლარაციამდე არ ინიციალიზდება. კოდის იმ მონაკვეთს, რომელიც ბლოკის დასაწყისიდან ცვლადის დეკლარაციის ხაზამდე გრძელდება, ეწოდება Temporal Dead Zone (TDZ). ამ მონაკვეთამდე let-ის ან const-ის გამოყენების შემთხვევაში ReferenceError-ს მივიღებთ

თანამედროვე JavaScript-ში ძირითადად ვიყენებთ let და const-ს

1.3. განმარტეთ Call Stack და Memory Heap: რა განსხვავებაა მათ შორის და სად ინახება მონაცემები?

Call Stack და Memory Heap მნიშვნელოვან როლს ასრულებს JavaScript-ში მეხსიერების მართვასა და კოდის შესრულებაში.

Call Stack არის სტრუქტურირებული მეხსიერების სივრცე, რომელიც მუშაობს LIFO (Last In, First Out) პრინციპით.
ის აკონტროლებს კოდის შესრულების თანმიმდევრობას და მართავს ფუნქციების გამოძახებებს.
როდესაც ფუნქცია გამოიძახება, ის ემატება სტეკის თავში, ხოლო დასრულებისთანავე სტეკიდან იშლება.

Memory Heap არის მეხსიერების არასტრუქტურირებული სივრცე, რომელიც გამოიყენება დინამიკური მონაცემების შესანახად.
მასში ძირითადად ინახება ობიექტები, მასივები და სხვა კომპლექსური მონაცემები.
ქოლსტეკისგან განსხვავებით, მათი ზომა და მეხსიერებაში არსებობის ხანგრძლივობა წინასწარ ზუსტად არ არის განსაზღვრული.

1.4. რა არის Event Loop (მოვლენათა ციკლი) Node.js-ში და როგორ მუშაობს ის?

Event Loop არის Node.js-ის მექანიზმი, რომელიც საშუალებას აძლევს JavaScript-ს შეასრულოს ასინქრონული და non-blocking ოპერაციები.
JavaScript ერთნაკადიანია, ანუ ერთ მომენტში Call Stack-ზე ერთი JavaScript ოპერაცია სრულდება.
თუ პროგრამას შეხვდა ისეთი ოპერაცია, რომელსაც დრო სჭირდება, მაგალითად ფაილის წაკითხვა, Node.js ამ ოპერაციის შესრულებას შესაბამის მექანიზმს გადასცემს და Call Stack-ს არ ბლოკავს.
როდესაც ოპერაცია დასრულდება, მისი callback შესაბამის queue-ში მოხვდება. Event Loop შეამოწმებს, არის თუ არა Call Stack თავისუფალი და შემდეგ callback-ს Call Stack-ზე გადასცემს შესასრულებლად.
ამიტომ Node.js-ს შეუძლია ბევრი ასინქრონული ოპერაციის მართვა ისე, რომ მთავარი JavaScript thread არ დაიბლოკოს.
